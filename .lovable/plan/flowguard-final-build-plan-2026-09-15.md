PERFORMANCE

==================================================

Very important.

- lazy-load heavy 3D

- limit geometry

- limit particles

- cap device pixel ratio

- pause inactive animations

- dispose Three.js resources

- avoid unnecessary React re-renders

- optimize mobile

- preload only essential assets

==================================================

- server-side authorization

- RLS

- secret storage
